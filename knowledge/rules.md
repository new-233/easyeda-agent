## 1. 板级与工艺默认

- 无特殊说明均默认为2层板、单层元件，板框最大尺寸为100mm×100mm，如果单面布局布线存在问题向我申请部分元件放置底层。

## 2. 线宽 / 线距 / 过孔默认

- 线宽默认为10mil，规则冲突情况下可适当减少线宽，原则为线宽略小于焊盘宽度或与焊盘宽度相同，但不得低于4mil。
- **扇出过孔距焊盘**：过孔中心到该网络焊盘**边缘** ≥ 2~3 倍线宽（10mil 线 → **≥20mil，推荐 30mil**）。禁止把过孔压在焊盘上、或贴着焊盘边缘打孔。换层点只能落在**离焊盘 ≥20mil 的直线段**上，不能落在焊盘出口或拐角上。
- **过孔避让**：过孔外径边缘到任何**异网络**焊盘/走线 ≥ 10mil；**禁止在芯片两排焊盘之间（100mil 间距）的走廊里打孔**。

## 3. 器件选用约定

- 薄膜电阻尽量选用0603或0805封装，陶瓷电容小于1uF的选用0603或0805封装，1-10uF选用1206封装，电解电容需考虑电路耐压选型，可参考相关数据手册。

## 4. 布局约定

- 板框需加半径100mil圆边，主控芯片尽量板靠中间，若有晶振则靠近芯片放置，去耦电容需贴近相关引脚；排针接口、usb接口等物理接口靠近板边放置；布局总体原则是尽量让布线顺畅，所以布局时要让相同网络飞线的交叉冲突尽可能少。
- **布局前先量化，再摆放（把拥塞前移，不要留到布线）**：摆放前先用离线分析算出飞线交叉数、哪些网络会互相抢同一条通道、每个器件出口有几条线要过。布局的验收指标是"飞线交叉数 / 预计通道占用"低于上一版；**交叉没降下来就不要进布线**，回去改分配或改布局。布局阶段解决一条，布线阶段就少一条硬网。
- **先改网络分配，再动布局和布线（很常用，优先级高于挪器件）**：排针/连接器的"引脚↔网络"映射是自由的。如果同组信号在芯片侧和排针侧的顺序相反（典型：主控 IO38~IO42 接到排针 8~11 脚，但两侧顺序倒置），飞线会成束交叉，这时**优先在原理图里重新分配这些排针引脚的网络**，让两侧顺序一致，交叉就成束消除，比在 PCB 上绕线或搬器件都干净。
  - 前提：互换的网络必须电气等价（例如都只是普通 GPIO 引出到排针），且不破坏差分对、时钟、电源等功能性配对。
  - 顺序：改原理图网络分配 → 同步到 PCB → 再布局 → 再布线；不要在布线中途改（会产生网络表不一致）。
  - 验证：改完先看飞线交叉数（`pcb layout-lint`）是否下降，再进入布线。
  - 同理可用于：把同组信号按"芯片侧物理顺序"重排到排针相邻脚位，减少扇出交叉。
- **元件与芯片的间距（异网络必须留出扇出通道）**：与芯片引脚**不同网络**的元件焊盘，距芯片引脚 **≥60mil（约 6 倍线宽）**；只有**同一网络**的元件（去耦电容、串联电阻、上拉电阻）才允许贴近，靠一条短线直接进焊盘。元件焊盘贴住异网络芯片引脚，会让该引脚扇不出来，只能"向芯片内部走线→打孔→再走回"，这是直角/锐角的根源。
- **元件朝向**：旋转元件让**同网络的焊盘朝向芯片**一侧；串联件（一端接芯片、一端接连接器）按"靠芯片的一端朝芯片"摆放。根本原则为同一网络的焊盘尽量聚拢，同网络焊盘靠近芯片不一定就是另一焊盘背向芯片，也有可能是垂直于这条连线。
- **元件不要压在一条长边的中点上**：落在中点意味着路径必须穿过它的焊盘（会产生 0°/45° 反折）；放在边的端部、成为叶节点。
- **排针/连接器上的电源脚（5V/3V3）必须放在与该电源入口同侧、靠近排针端部的位置**；禁止让电源干线横穿 IO 扇出区（反例：5V 放在排针中段，干线被迫斜穿 772mil + 竖走 979mil，切断了整条左侧 IO 走廊）。这不仅仅是电源脚的问题，本质上还是原理图中排针引脚排布存在问题，网络**电气等价** → **改原理图的引脚网络分配**，电气等价不一定要求是同一类信号，而是说这几个信号都是接在排针引脚上的，而排针的每个引脚物理属性是相同等价的，所以可以改引脚网络分配。

## 5. 布线 / 铺铜约定

- **电源网走"主干 + 支线"，禁止 A\* 式碎段**：先定一条主干，再给每个焊盘一条支线。判据：**走线段数 ≤ 焊盘数 × 3**，超过说明在绕路，停下来重排主干。
- **GND 用"过孔接到铺铜"，不要用长走线**：地是"接"过去的，孤岛焊盘打一个孔即可；GND 走线越短越好，孔多不是缺点。
- **慢速信号（EN/复位/普通 GPIO）宁打孔也不要一堆小折角**；敏感信号（差分、时钟）仍必须 0 孔。分界线是"这段铜会不会被当成传输线"。
- **摆放/旋转器件时先问"它的两个焊盘各自朝向谁"**：同网焊盘朝向对方（芯片/铺铜/连接器），异网焊盘背向，线自己就短了。

- **层资源按信号重要性分配（优先级高于"少改动"）**：差分对、时钟等敏感网络**优先占用整层**，禁止为了给普通 IO 腾通道而让它们换层；普通 IO 再去另一层找出路。
- **IO 扇出到排针只准 1 个过孔**：排针是通孔（两面可连），"芯片 SMD 脚 → 过孔 → 另一层 → 直接进排针焊盘"就够，禁止"下去再上来"（2 孔）。末段必须**水平进入排针焊盘**，不能沿排针列竖直穿过相邻 pin。

- 不得直角或锐角走线。统一走120°钝角线，90度拐角改成两个120度钝角，按网格点布线，不要走其他角度的线。
- **走线几何惩罚机制（布线时逐条自检，违反即重规划该条路径，不要留到最后的 DRC）**：
  - **线段方向**：只允许水平、垂直、45° 三种方向。出现任何其他角度的线段即为不合格（含焊盘中心到栅格路径的接线段）。
  - **直角惩罚（按网络类别分档）**：
    - **信号网络（普通 IO、时钟、差分、使能等）：直角和锐角一律杜绝**。内角 ≤90° 必须切成 45° 斜角（斜角长度 6~18mil；邻段很短时按邻段长度的 45% 收缩）。因此信号线的搜索代价更高（转弯代价、贴障碍代价都调高），要主动走开阔区，给切角留出余量；切角切不出来就重规划这条线，不许留直角。
    - **电源网络（3V3、5V、GND 等电源/地）：直角惩罚适当放宽**。一个电源焊盘同时引出多条线时，焊盘处形成的直角属于**铜皮汇流节点**，不是信号反射点，允许保留；能切就切，切不动（贴障碍/邻段过短）就保留直角，不算违规。但**锐角（内角 <90°）对任何网络都不允许**。
    - **过孔处一律不放直角**：换层点不能正好落在拐角上（进线方向与出线方向的夹角必须 ≤45°）。做法是把换层点挪到切角走线上（近似直线穿过过孔），而不是挪拐角。这一条对电源网同样适用。
    - 切角**必须做间距校验**：切角是"切向拐角内侧"，当拐角是绕障碍形成时，斜边的弦可能比原来两条边更贴近障碍，所以"切角只减铜、不必校验"是错的；校验不过就把斜角缩短（依次 1.0/0.7/0.5/0.35/0.25 倍），缩到 3mil 还不行才放弃切角。
  - **高频抖动惩罚（按"转弯"计数，不按 45° 小段计数）**：一个 90° 拐角被切成 45° 斜角后会变成两段相邻的 45° 转角，这算**一个转弯**，不是锯齿。所以判据是：
    - 两个**转弯**之间的直线段过短（<40mil 视为锯齿，尽量拉直或合并）；
    - 同一网络在 200mil 行程内出现 **3 个以上转弯**即判不合格。
    - 布线搜索本身必须带**转弯代价**和**贴障碍代价**（贴着障碍走就没有空间切角），从源头产生长直线段和开阔走线，而不是靠事后修补。
  - 以上规则同样适用于 GND 孤岛的连接线。
- **交叉冲突的处理判定（布线过程中的中断判定，不是最后才处理）**：逐条网络布线时若遇到飞线交叉/无法布通，按以下顺序判定：
  1. 若这一组交叉来自"同组信号在芯片侧与排针侧顺序不一致"（例如主控 IO38~IO42 对应排针 8~11 脚），且这些网络**电气等价**（都是普通 GPIO 引出）→ **改原理图的引脚网络分配**，让两侧顺序一致，然后同步到 PCB 再继续布线。
  2. 若不能改分配（涉及差分对、时钟、电源、或对外接口定义固定）→ 改变该条网络的布线路径（换层、绕行、调整出线顺序）。
  3. 判定与处理必须记录在案：改了哪些引脚、为什么等价、交叉数变化多少。
- **减少换面（换面影响信号质量，能不换就不换）**：排针/接线端子是通孔，**两面都能连**，禁止为了"接上排针"而换面。每个信号网络的过孔数目标为 **0**；"芯片焊盘 ↔ 排针焊盘"这类 2 焊盘网络必须 **0 孔**；同一网络超过 1 个孔必须写明理由。
- **电源先布是对的，但电源脚位置与干线走向必须在布线开始前定死**；电源干线不得横穿 IO 扇出区（见 §4 电源脚位置）。
- **差分对**：布线前先用 `pcb diff-pair create` 声明（需要等长的总线用 `pcb eq-group create`）；两条线**同层、0 过孔、等间距并行**一起布，不要各自走最短路；等长目标 **|skew| ≤ 5mil**（用 `pcb report` 量）。**为等长加的蛇形/绕弯造成的高频抖动是允许的**——这是"高频抖动惩罚"的唯一豁免。等长 ≠ 差分：先耦合布线，再补长度。
- **禁止冗余走线**：同一对焊盘之间只允许**一条**路径。落盘前先 `pcb.route.rip_up --net <net>`（幂等落盘），禁止"只加不拆"地重复落盘；禁止把 "routed but not merged" 的半成品落盘。布完自检：**每网环数 = 0、重复段 = 0、<6mil 退化小段 = 0**（脚本 `work/v4_redund.py` / `work/v4_dup.py`）。
- **连通性以平台为准**：`pcb net-path` / 官方 DRC 说通才算通；路由器自己的 `complete:true` 不算（实测会出现 `complete=true` 但平台判断开）。
- 以下为2层板规则：
- 布线顺序为：1、优先布电源线（3V3、5V等），电源线宽不得低于10mil，一般取15~30mil，具体线宽若数据手册中给出则参考，否则根据负载电流决定；供电线尽量短，不要太贴近板框；2、其次布重要信号线（差分信号线、时钟信号线等），重要信号线尽量短，靠近器件，尽量不打或少打过孔，差分信号线要检查是否严格差分；3、随后布一般信号线（普通io信号等不易受干扰信号线），若焊盘与线不处于同层则需通过过孔连接；4、 布局布线完成后检查drc，确保布线符合规则后添加泪滴，随后再次检查drc；4、GND网络在布局布线完成后对地铺铜，铺铜规则全部为直连，孤岛GND使用过孔连接，确保整板共地。最后再次检查drc，确保全部通过无问题。

## 9. 验收标准（什么算"做完了"）

- **完工前必须按本文件逐条核对，并把每条的实际检查结果写出来（数字/证据），不许只写"通过"。** 没有实际跑过检查的条目一律标"未验证"，不得据此宣布完工。用户明确要求（2026-10-18）："画完之后重新核对 rules 中每一条，检查无误后再确认完工"。
- 所有相同网络均正确连接、不存在悬空，没有网络孤岛，drc检查全部通过。
- **DRC 之外还要过四项量测门（DRC 不查冗余、不查过孔质量）**：
  ① 同网过孔↔焊盘边缘 ≥20mil、异网 ≥10mil；
  ② "芯片↔排针"2 焊盘网络 0 过孔，全板过孔数取最小；
  ③ 每网冗余环数 = 0、重复段 = 0、<6mil 退化段 = 0（GND 铺铜除外）；
  ④ 差分对 |skew| ≤5mil（`pcb report`）。
  四项任一不通过就不算做完。

## 10. 布线遇阻的处理顺序（禁止死磕硬算）

- **优先级：① 改完后整板布线最顺畅、质量最高 ＞ ② 改动最小。** 两者冲突时永远选 ①：
  宁可多改布局/原理图，也不为了"少动手"去硬算一条不完美的路径。
- **布线开始前先做"第 0 级"**：① 排针电源脚位置（§4）② 排针引脚↔网络分配（§4）
  ③ 异网络元件与芯片的间距（§4）——三件事定死再开始布线。
  "电源先布切断 IO 走廊""元件贴芯片堵住扇出"这两类问题，只有在这一步能解；
  布到一半再改代价最大（要拆已落的铜）。
- 布线遇到困难（找不到路径、反复重试失败、或只能算出带锐角/直角/高频抖动的路径）时，
  **禁止继续硬算、死磕这条线**。停下来，按下面顺序升级判定该改哪一层：
  1. **挪线（改动最小）**：把挡路的其他网络的一段走线移开/改向/换层（必要时只拆那一小段重布），
     给当前网络腾出通道。
  2. **改布线顺序/嵌套**：同组扇出按芯片侧焊盘的物理顺序重排（最外侧的先走）；
     互相抢同一出口的相邻网络**整组拆掉一起重布**，不要一条条试。
  3. **改布局**：移动/旋转器件，让飞线交叉和通道争用从源头消失（去耦贴近引脚、
     串阻/ESD 贴近连接器、连接器朝向与引脚顺序对齐芯片侧）。
  4. **改原理图引脚分配**：电气等价的网络重新分配到"几何上顺"的引脚（见 §4）。
- **升级判据**：如果 1/2 只能让这一条网勉强布通，而 3/4 能让**整组/整板**的路径更顺，
  就直接做 3/4，即使改动更大。比较的是"整板指标"——交叉数、转弯数、过孔数、走线总长、
  硬网数量——不是"这一条网通没通"。
- **明确禁止的反模式**：为了让一条网布通，硬走一条贴障碍、带锐角/直角的路径，
  再用"记录偏差放行"签字过关。这是最差解，它把问题留进了成品；
  遇到这种情况应当回退，改走 2/3/4。
- 每次升级都要记录：改了哪一层、改了什么、为什么、整板指标变化多少（改前 → 改后）。
- 反过来也一样：改布局/改分配**必须用指标证明收益**，不能凭感觉反复搬器件。
  改完交叉数/硬网数没变好就回退。
